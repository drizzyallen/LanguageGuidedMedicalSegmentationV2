# Phase 0 — Results (Tasks 0.6 and 0.7)

Image-only benchmark: U-Net (LViT), TransUNet (R50-ViT-B_16), nnU-Net v2 (2D) on QaTa-COV19 and MosMedData+
with the official LViT splits, 3 seeds per method (1001, 1002, 1003), 18 runs in total.
Machine-readable tables: `results/phase0_main_results.csv`, `results/phase0_pairwise_comparisons.csv`
(generated by `src/analysis/phase0_results.py`).

## Evaluation protocol (Task 0.5)

- Test sets: LViT test split — QaTa-COV19 2113 images, MosMedData+ 273 images; identical for all runs.
- Targets: common 224×224 prepared masks (Task 0.2).
- One evaluator for all methods (`src/evaluation/evaluate.py`): 224×224 predictions, lesion = probability ≥ 0.5.
- Metrics per test image: Dice; IoU of the lesion (mIoU = mean over images); HD95 and ASSD in 224×224 pixels.
  If a prediction is empty while the target has a lesion, HD95 and ASSD are set to the image diagonal
  (316.8 px). No test target is empty.
- Checkpoints were selected by validation Dice only; each test set was predicted once per run.
- nnU-Net predictions use nnU-Net's default inference (sliding window with test-time mirroring);
  U-Net and TransUNet use a single forward pass, as in their official code.

A consistency check over all 18 runs confirmed identical test IDs, identical targets, identical evaluation
settings, 224×224 binary predictions, and exact agreement between stored and recomputed metrics.

## Pairwise comparisons (Task 0.7)

Per dataset: each test image's Dice is averaged across the 3 seeds within each method; the same images are
aligned; ΔDice = mean of (A − B) in percentage points. 95% CI: paired percentile bootstrap over test images
(10,000 resamples). p: two-sided Wilcoxon signed-rank test on the paired per-image Dice. Holm correction
across the three comparisons within each dataset.

| Dataset | Method A | Method B | ΔDice | 95% CI | Raw p | Holm p |
|---|---|---|---:|---|---:|---:|
| QaTa-COV19 | U-Net | TransUNet | −1.06 | [−1.45, −0.66] | 1.3e-22 | 4.0e-22 |
| QaTa-COV19 | U-Net | nnU-Net | −1.25 | [−1.66, −0.84] | 4.1e-21 | 8.1e-21 |
| QaTa-COV19 | TransUNet | nnU-Net | −0.19 | [−0.62, 0.24] | 0.019 | 0.019 |
| MosMedData+ | U-Net | TransUNet | +1.90 | [−0.22, 4.00] | 3.4e-4 | 6.7e-4 |
| MosMedData+ | U-Net | nnU-Net | −1.67 | [−3.71, 0.26] | 0.55 | 0.55 |
| MosMedData+ | TransUNet | nnU-Net | −3.57 | [−4.66, −2.43] | 7.8e-17 | 2.4e-16 |

Reading the table:

- The CI describes the **mean** per-image difference; the Wilcoxon test asks whether per-image differences are
  **systematically shifted** (rank-based). The two can disagree. For TransUNet vs nnU-Net on QaTa-COV19 and
  U-Net vs TransUNet on MosMedData+, the Wilcoxon test is significant after Holm correction while the bootstrap CI
  of the mean difference includes 0: one method is better on more images, but the average gain is small or
  uncertain. Both numbers are reported; neither should be read alone.
- Comparisons where both agree: on QaTa-COV19, TransUNet and nnU-Net are both better than U-Net (≈1.1–1.3 points);
  on MosMedData+, nnU-Net is better than TransUNet (≈3.6 points). U-Net vs nnU-Net on MosMedData+ is not significant.

## Notes

- MosMedData+ results vary more across seeds (Dice SD 0.8–2.3 points vs 0.2–0.4 on QaTa-COV19) and have wider CIs,
  consistent with its small test set (273 images) and small lesions (≈1.5% of the image on average).
- The LViT MosMedData+ split is slice-level: 183 of the 273 test slices come from CT volumes that also have slices
  in the training set (see `reports/PHASE0_DATA_SUMMARY.md`). MosMedData+ scores may therefore overestimate
  performance on unseen patients; this affects all methods equally.
- Empty predictions (lesion missed entirely) per run range from 6–25 on QaTa-COV19 and 2–13 on MosMedData+; each
  contributes the worst-case distance (316.8 px) to HD95/ASSD, which drives most of the seed-to-seed spread in
  those metrics (e.g. U-Net MosMedData+ seed 1003: 13 empty predictions, ASSD 20.1 px).
- For reference, the LViT repository reports U-Net Dice 79.02 (QaTa-COV19) and 64.60 (MosMedData+); our U-Net
  obtains 78.35 and 70.36 under the protocol above. Evaluation details differ, so this is not a direct comparison.
- Runs: training on RTX 3090 GPUs, Oct 20 – Nov 4, 2026. Three runs interrupted by a server failure on Oct 22
  were restarted from scratch; no completed run was modified.
